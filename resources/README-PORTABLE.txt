TMS-MDEditor ポータブル ZIP 版

このフォルダを任意の場所へ展開し、直下の TmsMdEditor.exe から起動してください。
本体は app\TmsMdEditor.exe です。直下の exe は起動用です。インストール、UAC 昇格、スタートメニュー登録、ファイル関連付けは行いません。

■ 注意（必ずお読みください）

- このフォルダごと移動・コピーしてください。直下の TmsMdEditor.exe だけを別の場所へ置くと起動できません。
- app\portable-mode.json は削除しないでください。
  削除するとインストーラ版として動作し、設定が %APPDATA% へ保存されます。
- Windows の SmartScreen 等で警告が出ることがあります。
  「詳細情報」から実行できる場合は、その操作で問題ありません。
- v1.1.0 時点ではコード署名はありません。

■ データの保存場所

アプリが作る設定・ログ・WebView2 キャッシュは、すべて app フォルダ内の data へ保存します
（TmsMdEditor.exe と同じ階層）。C ドライブ上でも USB 上でも同じです。
ログは app\data\logs\app-YYYYMMDD.log です（%APPDATA% には書きません）。

顧客端末の %APPDATA% や %LOCALAPPDATA% へ、アプリ自身の永続データは書きません。
data フォルダは初回起動時に作成されます。配布 ZIP には含まれません。

ポータブル版では設定画面からデータ保存先を変更できません。

■ 更新手順

1. TMS-MDEditor を終了する
2. 公式ページから新しいポータブル ZIP を入手する
3. 新しいフォルダへ展開する（実行中のフォルダへ上書きしない）
4. 旧版の app\data フォルダを新版の app\data へコピーする
5. 新版を起動して設定を確認する
6. 問題がなければ旧版フォルダを削除する

自動ダウンロードや自動インストールは行いません。
更新がある場合は、アプリが公式ページへ案内します。

公式ページ: https://tm-systems.jp/#apps
